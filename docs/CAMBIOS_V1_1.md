# HELION v1.1 · Mejora visual del mapa de divisiones

**Estado:** implementado y sujeto a revisión visual del usuario.

**Motivo:** 16 pines superpuestos (especialmente Valle de México) y mapa difícil de interpretar.

**Cambio:** 14 marcadores visuales para 16 divisiones; se agrupan las 3 de Valle de México. Se incorpora directorio de 16 tarjetas, selección sincronizada, interacción de teclado y panel con notas de alcance. Se ajustan las anclas artísticas para permanecer en el esquema y se conserva la marca HELION.

**Validación:** probar que las 16 tarjetas puedan seleccionarse y que las 3 de Valle de México alternen mediante el panel lateral. Comprobar móvil y escritorio.

**Advertencia científica:** anclas dibujadas manualmente sobre una silueta, NO coordenadas oficiales ni polígonos de divisiones. Pendiente conseguir cartografía verificable.

**Archivos cambiados:** `js/data.js`, `js/app.js`, `css/styles.css` y documentación. No se ha tocado `index.html`.
