# Fotografías de HELION v1.8

Las imágenes son fotografías reales de infraestructura o entorno energético. Se muestran como ilustraciones de tecnología o región; salvo la foto nuclear, no identifican la central seleccionada en el mapa. Las copias WebP se redimensionaron y comprimieron para el sitio, sin alterar los datos del Atlas. Cada ficha enlaza al archivo original y a sus condiciones de reutilización.
