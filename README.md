# ⚡ HELION | Atlas Eléctrico de México

### De la generación al consumidor

**Proyecto académico TE1020 — Tecnológico de Monterrey | 2026**

HELION es una aplicación web educativa e interactiva desarrollada para explorar cómo México aprovecha sus recursos energéticos para generar, transmitir y distribuir electricidad.

El proyecto combina principios de ingeniería eléctrica, visualización de datos y desarrollo web para presentar información técnica de manera accesible, visual y dinámica.

La aplicación utiliza información de documentos oficiales de la Comisión Federal de Electricidad (CFE), junto con fuentes institucionales complementarias.

## Funcionalidades principales

- **Recursos energéticos:** clasificación de fuentes de energía, diagramas de transformación y actividades interactivas.
- **Generación eléctrica:** centrales de generación, mapas geográficos, gráficas y comparaciones entre 2022 y 2024.
- **Transmisión eléctrica:** regiones del sistema eléctrico mexicano y simulador de corriente trifásica y pérdidas resistivas.
- **Distribución eléctrica:** divisiones regionales de CFE, indicadores de infraestructura y simulador de transformadores.
- **¿Sabías que?:** veinte hallazgos documentados y una sección histórica sobre la reforma energética mexicana.

La aplicación incluye filtros, visualizaciones cuantitativas, actividades de aprendizaje y referencias documentales.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- SVG para mapas, gráficos y diagramas
- GitHub Pages para publicación

El diseño mantiene la identidad visual original de HELION, utilizando azul profundo, dorado solar y turquesa.

## Metodología de desarrollo

El proyecto se desarrolló de manera iterativa mediante tres herramientas de trabajo:

**ChatGPT:** coordinación académica, planeación, revisión de requisitos y seguimiento de versiones.

**ChatGPT Work:** investigación documental, auditoría de estadísticas y validación de fuentes institucionales.

**Codex:** implementación de correcciones, desarrollo web y pruebas funcionales.

Cada versión buscó mejorar la exactitud técnica, la experiencia del usuario y el funcionamiento general de la aplicación.

## Fuentes y limitaciones

Las estadísticas principales proceden de los Informes Anuales de CFE 2022, 2023 y 2024, complementados con documentos de SENER, CENACE y legislación mexicana.

Los mapas incluyen referencias territoriales aproximadas cuando no se dispone de coordenadas exactas verificadas. Los simuladores representan modelos eléctricos didácticos con supuestos y limitaciones explícitos.
