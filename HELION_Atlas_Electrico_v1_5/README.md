# HELION | Atlas Eléctrico de México — v1.5

Aplicación educativa TE1020 en HTML, CSS y JavaScript. Edición independiente para revisión académica local. No se modificó ni publicó el repositorio original.

Conserva cinco módulos, tres mapas, 15 centrales, 16 divisiones (14 marcadores), 18 tarjetas, 20 hallazgos, dos simuladores, filtros y gráficas. Las precisiones de datos y sus pendientes se explican en la aplicación.

Instalación: [instrucciones](docs/COMO_INSTALAR_V1_5.md). Evidencias y límites: [fuentes](docs/FUENTES_Y_LIMITACIONES.md). Cambios: [registro](docs/CAMBIOS_V1_5.md). Pruebas: [reporte](docs/REPORTE_PRUEBAS_V1_5.md).

Los documentos v1.1–v1.4 son antecedentes históricos; prevalecen los documentos v1.5. El tutorial antiguo de publicación no autoriza publicar esta versión.
